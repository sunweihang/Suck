## 1. P0：评测当问题报，改完立刻变好

### 1.1 第 33 关缩放显示 ✅

- **评测**：33 关存在关卡缩放显示问题。
- **落地**：`fitPlayLayout` 按真实屏宽高比 + 雕塑包围盒适配。先拉远正交相机（最多 ×1.42），不够再略缩砖。进关改 `orthoHeight` 时立刻重铺 `WorldBg`，避免两侧露米色清屏。
- **涉及**：`GameConfig.ts`、`LevelCatalog.ts`、`GameBootstrap.ts`、`ToyBackdrop.ts`、`UgcEditor.ts`。

### 1.2 镂空能看见颜色但消不掉、也不失败 ✅

- **评测**：镂空处能看到颜色，打不到，游戏不失败，卡住。
- **落地**：
  1. 朝相机的 3D DDA 视线：能看见的外壳/内壁就能打。
  2. 判负改为「已解锁的坑都满 + 转墙也吸不到 + 没有炸弹/铲子」。锁着的边坑不再挡住失败。`_canEventuallyAbsorb` 不再把埋住的砖算成还能吸。
- **涉及**：`BattleDirector.ts`（`_hiddenBehind`、`_camExposed`、`_checkStuckLose`）。

### 1.3 炸弹（以及钩子/铲子）点选无反馈 ✅

- **评测**：点炸弹后没有任何反馈，要点对应区域才生效，突兀。
- **落地**（跟手改过一轮，以现在为准）：
  - 有库存：点图标直接进入点选；再点一次取消。没库存才弹商店。
  - 铲子场上没有可铲炮塔时灰化。
  - 不选手指、不选黄圈、不出顶部提示条（会误导 / 难看）。
  - 勾爪 / 铲子使用特效：底部钉在点到的炮塔上，绕接触点转。
- **涉及**：`GameBootstrap.ts`、`BattleDirector.ts`、`PlayHud.ts`、`TutorialGuide.ts`、`ItemFlyFx.ts`。

**P0 验收**：33 关墙完整入画、背景铺满；复现镂空关会判负或能打到；点道具立刻进入点选，再点取消。35 关起结算仍只有「双倍领取」，保持现状。

## 2. P1：收经济、改关卡（评测强建议）

### 2.1 金币过松、通关直接给道具 ✅

- **评测（强）**：通关金币太多；道具是主广告口。建议 50–70 关累计金币才够换 1 个道具；单独商店；限制金币可买种类；看广告刷新；通关不要直接给道具。
- **落地**（2026-08-22，本轮只动数值和掉落，未做新商店 UI）：

| 项 | 旧值 | 新值 |
| --- | --- | --- |
| 开局 | 200 | 30 |
| 通关 / 失败 | +25 / +10 | +8 / +3 |
| 看广告金币 | +50 | 50（不动） |
| 开槽 | 600 | 2000（避免比道具还便宜） |
| 道具价 | 洗牌 20、钩子 40、铲子 40、炸弹 30 | 洗牌 600、炸弹 800、钩子/铲子 1000 |
| 通关宝箱 | 每 5 关，1–2 个道具 + 40–80 金 | 每 5 关，只给 20–30 金 |

粗算纯通关（含宝箱、不含广告）：50 关 ≈ 680（1 个洗牌），60 关 ≈ 810（1 个炸弹），70 关 ≈ 940（接近 1 个钩子）。教学关 30 金买不起任何道具；教程仍直接发试用道具。
- **后置（P2）**：金币只能买部分道具、看广告刷新、射击加速卡、困难关基础金币更高、领取 ×3。
- **涉及**：`PlayerWallet.ts`（`GOLD`）、`ChestLoot.ts`。`ItemShopPanel` / 结算宝箱 UI 跟常量走，不用改。

### 2.2 第 39、45 关故意刁难

- **评测（强）**：大面积色块对应炮塔连续堆在某列底部，玩家觉得关卡不公平，不像自己操作问题。
- **现状**：39 = 2612 体素 / 41 炮，45 = 3136 体素 / 50 炮；无铁板等机关。仓库**没有运行时 AI 生关**，关卡是导入体素。
- **改法**：重排炮序或重做这两关，避免「一整列底部同色炮连发、墙却打不到」。不要指望改生成器一句话。
- **涉及**：`assets/resources/levels/p003.json`（L31–40）、`p004.json`（L41–50）；必要时 `levels/catalog.json` 再打分片。

### 2.3 炮弹剩余很多 / 有的炮只有 1–2 发

- **评测（一般）**：有的 3D 物体消完还剩很多炮弹；有的炮只有 1–2 发。
- **改法**：按各颜色墙体量重算 `units[].power`，扫一批关，不只改 39/45。不要用「通关吞掉余弹」掩盖数据。
- **涉及**：关卡 JSON、`tools/import-voxel-levels.js` / `tools/level-io.js`（若有按体积分配 power 的逻辑，一并修生成规则）。

### 2.4 前期难度与节奏

- **评测（强）**：教学后从 3–5 关加大，普通人需要看广告才能过；整体 **1 困难 + 2–3 普通**；单关先易后难（约 1 分钟后再加压）；好看的关往前放。
- **现状**：前几关是教学（转墙、洗牌、合并、钩子、铲子、炸弹）；`HIDDEN_QUEUE_AFTER_LEVEL = 30`，前 30 关队列不藏色。
- **改法**：
  1. 教学结束后（约第 3–5 关）插入真正会卡住、需要道具/广告的关。
  2. 全表按 1 难 + 2–3 普通重排，难度随关卡号缓升。
  3. 视觉好看的关适当前置。
  4. 「单关内先暴露好消的颜色」单独做，比调顺序重，本轮能做几关做几关。
- **涉及**：关卡顺序（catalog / shards）、可选提前 `HIDDEN_QUEUE_AFTER_LEVEL`。

**P1 验收**：新号打到约 50 关，金币不够随便买道具（经济已按此改完）；39/45 不再「一列底部堵死」；3–5 关普通人会考虑看广告或用道具。
