3. 种植（逻辑场景 index.json）

路径示例：assets/resources/scenes/600/logic/600/index.json

{
  "logicId": 600,
  "assetsSceneId": 600,
  "monsterSpawn": {
    "formatVersion": 1,
    "logicSceneId": 600,
    "resourceSceneId": "600",
    "layers": [
      {
        "layerId": 1,
        "layerName": "default",
        "items": [
          {
            "position": { "x": 16.99, "y": 0.5, "z": 12.43 },
            "scale": { "x": 2.3, "y": 1, "z": 2.6 },
            "enemyKeys": ["Enemy02"],
            "enemyCount": 1,
            "level": 1,
            "spawnShape": "area"
          }
        ]
      }
    ]
  }
}
字段说明
layerId层号，必须与节奏表 layer_id 一致
position点位坐标；区域则为中心
scale.x/z区域大小（XZ）；点位可忽略
enemyKeys怪物 key（如 Enemy02，对齐 TbMonster.key）
enemyCount区域内展开只数；点位一般为 1
spawnShapearea / point
编辑器提示「表已关联」= 节奏表已有对应 (logic_scene_id, layer_id) 行。
