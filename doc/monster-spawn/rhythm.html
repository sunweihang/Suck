4. 节奏表（spawn_config.xlsx）

路径：config/luban/Datas/spawn_config.xlsx
Bean：__beans__.xlsx 中的 SpawnStartTrigger / SpawnOnCleared（Luban 正式多态，sep=,）

4.1 列说明

列类型说明
idint行主键，全表唯一
logic_scene_idint逻辑场景 ID
layer_idint层 ID = 种植卡 #ID
start_triggerSpawnStartTrigger何时开始刷本层
on_clearedSpawnOnCleared本层怪全部死光后做什么
gen_intervalslist<float>，; 分隔分波间隔（秒），可空
gen_numslist<int>，; 分隔每波数量，可空
sort_orderint同场景排序权重

4.2 多态单元格写法

  • 无参：只写类型名，如 ImmediateStart
  • 有参：类型名,字段1,字段2,...（顺序与 bean 字段一致）
  • 导出 JSON 形如：{ "$type": "RespawnAction", "interval": 3, "max_rounds": 0 }

4.3 start_trigger

单元格含义
ImmediateStart进场 / 层激活后立刻刷
AfterLayerStart,<layerId>指定层清完后再开本层
RangeStart,<r>,<x>,<y>,<z>玩家靠近中心半径内再刷
ManualStart,<key>手动唤醒（预留）
OnHpBelowStart,<layerId>,<hp>目标层血量 ≤ 比例（0~1）后开

4.4 on_cleared

单元格含义
EndAction本层结束，不再由本层驱动后续
RespawnAction,<秒>,<轮数>清完等待后本层再刷一轮；轮数 0=无限
TriggerLayerAction,<layerId>清完去激活另一层
LoopBackAction,<layerId>,<轮数>清完跳回某层；轮数 0=无限

4.5 gen_nums / gen_intervals（分波）

两列都留空 = 本层种植点一次全刷完。

gen_numsgen_intervals行为
3;4;32;5先 3 → 等 2 秒 → 再 4 → 等 5 秒 → 再 3
（空）（空）一次刷完
gen_intervals 通常比 gen_nums 少 1 个（最后一波后不用再等）。 分波是开刷时怎么出；与死光后的 on_cleared 无关。
