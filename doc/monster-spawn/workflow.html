2. 工作流（推荐顺序）

  1. 创建 / 打开逻辑场景（绑定资源场景，如资源 600 → 逻辑 600）
  2. 种植编辑器：加区域/点位，选单位（TbMonster / 模型 TbAvatar），拖位置后点 保存
  3. Excel：在 spawn_config.xlsx 为该 logic_scene_id + layer_id 配节奏
  4. 导出 Luban：./tools/dataTools/export.sh
  5. 正式进关验证（LevelStart 会启动刷怪；SkillDebug 会跳过，不会自动刷关卡怪）
运行时入口：LevelController.LevelStart → LogicSpawnLoader（种植）× SpawnConfigProvider（节奏）→ MonsterSpawnCoordinator。
无种植数据时回退 Prefab 上的 EnemyBornInfo。
