6. 完整最小闭环（以 600 为例）

  1. 种植
    Cocos 打开「逻辑场景种植」，选逻辑 600 → 加区域：单位 Enemy02，数量 5 → 确认卡上 #ID = 1 → 点绿色 保存
  2. 节奏（死光 3 秒后再刷，无限）
    打开 config/luban/Datas/spawn_config.xlsx，保证有： 
    id=600  logic_scene_id=600  layer_id=1
start_trigger=ImmediateStart
on_cleared=RespawnAction,3,0
gen_intervals=（空）  gen_nums=（空）  sort_order=1
  3. 导出
    ./tools/dataTools/export.sh
    确认 tbspawnconfig.json 出现： 
    {
  "id": 600,
  "logic_scene_id": 600,
  "layer_id": 1,
  "start_trigger": { "$type": "ImmediateStart" },
  "on_cleared": { "$type": "RespawnAction", "interval": 3, "max_rounds": 0 },
  "gen_intervals": [],
  "gen_nums": [],
  "sort_order": 1
}
  4. 进关
    正式流程进房间 600：应立刻刷出种植怪；杀光后约 3 秒再刷一轮。
